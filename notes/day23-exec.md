## 二 主体 B：优雅退出（SIGTERM）

- 要写的（5 行量级）：`listen` 之后接 `process.on('SIGTERM' | 'SIGINT')` → **先停收新请求、关库、再退出**，并打一行日志（内容自己定，比如"收到 SIGTERM，正在优雅退出"）。
- ⚠️ **Windows 收不到 SIGTERM** → 本机验不了；**在容器里验**：

```powershell
docker compose up -d --build app     # 会构建镜像（慢就先记一笔，别在这儿烧时间）
docker ps                            # 找到 app 容器名
docker stop <容器名>                  # docker stop 发的正是 SIGTERM
docker logs <容器名>                  # 判据：看到你那条"优雅退出"日志
```

（若 `--build` 不稳：**记一笔"待容器里补验"**，下个时段或明天补 —— 但不许当它不存在。）
