# Day 1 学习指引：JS 类型系统

## 先更正一个说法

我原本写的"8 种原始类型"不准确。ECMAScript 规范的定义是**8 种数据类型**：

**7 种原始类型（primitive）**：`string`、`number`、`bigint`、`boolean`、`undefined`、`symbol`、`null`
**1 种引用类型（reference）**：`object`（数组、函数、Date、Map 等都算 object）

记住这个区分，因为它直接决定了**变量存的是值本身还是地址**——这是后面所有类型转换、比较行为、深浅拷贝问题的总根源。面试官很爱在这里做区分，说错会很扣分。

### A 组

| 题 | 答案 | 为什么 |
|---|---|---|
| Q1 | `'object'` | 历史遗留 bug：`null` 在内存里用全 0 表示，而 `typeof` 靠检查前几位判断类型，全 0 恰好匹配 object 标签。错了几十年，改不了（改了会破大量老代码）。**面试高频**。 |
| Q2 | `'undefined'` | 正常。 |
| Q3 | `'number'` | `NaN` 的含义是"无效的**数值**运算结果"（Not a Number），但它本身属于 number 类型。 |
| Q4 | `'function'` | 规范里函数是 object 的子类型，但 `typeof` 特判返回 `'function'`，方便判断可调用性。 |
| Q5 | `'object'` | 数组是对象，`Array.isArray()` 才是正确的判断方式。 |
| Q6 | `'bigint'` | 任意精度整数，字面量后缀 `n`。 |
| Q7 | `'function'` | `class` 是构造函数的语法糖，本质是可调用对象。 |
| Q8 | `'string'` | 先算里层 `typeof 1` 得 `'number'`，再算外层 `typeof 'number'` 得 `'string'`。`typeof` 永远返回字符串。 |

### B 组

**总规则**：`+` 只要有任一侧是字符串，就做**字符串拼接**；其他运算符（`-` `*` `/`）**强制转数字**。

| 题 | 答案 | 为什么 |
|---|---|---|
| Q9 | `'52'` | `+` 遇字符串 → 拼接。 |
| Q10 | `3` | `-` 只做减法 → `'5'` 被转成数字 5。 |
| Q11 | `2` | `true` 转数字是 1。 |
| Q12 | `''` | 数组转字符串是 `''`（空数组），`'' + ''` = `''`。 |
| Q13 | `'[object Object]'` | `[]` → `''`，`{}` → `'[object Object]'`，拼接。 |
| Q14 | `'1,23'` | 数组转字符串是用逗号连接元素：`'1,2'` + `'3'` = `'1,23'`。 |
| Q15 | `'33'` | **从左到右**：先 `1+2=3`（都是数字，相加），再 `3 + '3'` → 拼接 → `'33'`。 |
| Q16 | `'321'` | **从左到右**：先 `'3' + 2 = '32'`（拼接），再 `'32' + 1 = '321'`。 |

Q15/Q16 是同一个考点：**`+` 是从左到右逐个结合的，前面一旦变成字符串，后面全变拼接。**

### C 组

| 题 | 答案 | 为什么 |
|---|---|---|
| Q17 | `true` | 规范特殊规定：`null` 和 `undefined` 互相 `==` 为 true（且只跟彼此相等）。 |
| Q18 | `false` | `===` 不做类型转换，类型不同直接 false。 |
| Q19 | `false` | `NaN` 不等于任何值，**包括它自己**。判断用 `Number.isNaN()`。 |
| Q20 | `true` | `==` 在类型不同时转数字：`''` → `0`，`0 == 0`。 |
| Q21 | `true` | 两边都转数字：`[]` → `''` → `0`；`false` → `0`。经典坑。 |
| Q22 | `false` | `===` 类型不同（object vs boolean）直接 false。 |

**Q21/Q22 是`==`和`===`差别的标准例证，务必能讲清。**

### D 组

| 题 | 答案 | 为什么 |
|---|---|---|
| Q23 | `2` | 对象存的是**地址**。`b = a` 复制的是地址，两者指向同一个对象，改哪个都是改同一个。 |
| Q24 | `1` | 数字是原始类型，存的是**值本身**。`y = x` 复制了一份值，改 `y` 不影响 `x`。 |
| Q25 | `false` | `===` 不比类型转换，一个是 object 一个是 number。**永远不要用 `new` 造包装对象。** |
| Q26 | 合法，`obj.a` 是 `2` | `const` 锁的是**变量绑定**（不能让 `obj` 指向别的东西），不是对象内容。所以可以给 `obj` 换属性，但不能 `obj = {}`。想真正冻结用 `Object.freeze()`。 |

## 三、今天该怎么用 AI（重要）

今天的 AI 用法决定了你是"学会"还是"以为自己学会"。**正确的问法**：

✅ **带着具体困惑问**
> "我预测 `[] + []` 是 `'[object Object]'`，实际是空字符串，为什么？"

✅ **让 AI 出题考你**
> "出 5 道关于 `==` 隐式转换的题考我，由易到难，一次只给一题，等我回答再给下一题和解析。"

✅ **追问设计动机**（面试加分项）
> "`typeof null` 返回 `'object'` 是 bug，为什么规范一直不修？"

❌ **错误的问法**
> "给我讲一下 JS 的类型转换"

后者是让 AI 替你把上面的章节读一遍——你读到了文字，但什么都没进脑子。**主动回忆（先猜）失败带来的记忆强度，是被动阅读的 3 倍以上。**
