## N. 算法与数据结构（LeetCode，10/9 起）

- 两数之和（暴力 O(n²) 74ms / 7.78% → **哈希表 O(n)** 73% 那次 = "先想复杂度再动手"的教材）
- **栈（STACK）**（一摞盘子 / **LIFO 后进先出** / `push` · `pop`（**返回它拿走那个**）· `at(-1)`（**只看不拿**）· `length === 0`（判空）★
- **为什么栈全 O(1)**（**只在顶部操作，从不搬动其他元素** —— 对比 `shift`/`unshift`/`splice` 要搬 → O(n)）★
- **何时该想到栈**（"**最近那个还没处理完的必须先处理**"：配对 / 嵌套 / 回退 / DFS）★
- 有效括号 LC20（两个边界：**栈空遇闭括号** / **扫完栈非空**；牙 = `"([)]"`）★
- **复杂度怎么算**（① 定 n ② 数每个元素被碰几次 ③ 只留最高次项 ④ 空间只算"额外的"）★
- **常见档位**（O(1) / O(log n) / O(n) / **O(n log n) ← `sort`** / O(n²)）★
- **内置方法的代价**（`includes`·`indexOf`·`shift`·`slice`·`split` = O(n)；`sort` = O(n log n)；`Set.has`·`push`·`pop`·`str[i]` = O(1)）★
- **递归的复杂度**（没有 `for` 也可能是 O(n) / O(2ⁿ)）★
- **"没有循环就一定 O(1)"** = 危险经验法则（反例：递归、内置方法内部有循环）★
- **最坏情况** ＋ 复杂度是"**涨势**"不是"秒数"（8ms / 击败 9.25% 那次）★
- **输入只读、状态另存**（另起一个数组，别在输入上原地删 → 原地删是 O(n²)）★
- **索引基准 0 起 vs 1 起**（off-by-one；内部统一 0 起、**只在展示层换算一次**）★
- **哨兵值（sentinel）**（`-1` = 找过没找到；`null` = 不适用 —— **两件不同的事**）★
