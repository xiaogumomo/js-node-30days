## 二、方法（2026-10-17 第二次改版：**知识点先行**）

**每块 40–50 分钟，五步。顺序不能反 —— 提问必须在知识点讲过之后：**

2. **示例代码**（逐行标注"这行对应知识点的哪一条"）→ **合上重打**（不许复制；`node --check` + 跑）
3. **AI 提问**（3 个概念题 + 3 个"改一处 → 先预测 → 再跑"）
4. **讲 30 秒**（这块解决什么问题 / 关键机制）
5. **（可选）回访自己代码** —— 顺序反了会低效

> **两次改版的账（都是 AI 的）**：
> ① 10/17 第一次：让他"自己去代码里找" → 他指正"不知道该找什么，效率很低" ✓ 对（回访法的前提是**知道名字**）

> **定死：先知识点 → 再示例代码 → 再提问。**

## 四、D7 大考（10/24 周六）

**不看稿讲 p2 一条请求链 5 分钟**，必须一步不跳：

```
浏览器/curl 发请求(带 token)
 → HTTP 到 Fastify
 → onRequest 钩子：读 authorization: Bearer → 验 JWT → 挂 req.userId（失败就 401）
 → 路由 GET /tasks 处理函数
 → db.js listTasks(userId)
 → SQL: SELECT ... WHERE userId = $1 ORDER BY id
 → pg 连接池借一条连接执行 → rows
 → toTask 行映射（Number(r.id)、!!r.done）
 → reply.send(...) → 200 JSON
（出错的路径：/boom 或非法 JSON → setErrorHandler → 500/400 + JSON，进程不崩）
```

**判据**：① 5 分钟内讲完 ② 每一步能指出**文件:行号** ③ 回答两个追问（"为什么隔离写在 SQL 里而不是查出来再过滤？""为什么能在数据库层就返回 404？"）
