### B. 逐条清单（可以逐条打勾恢复）

**`curry`（4 条）**
1. [ ] `curry(fn)` 收的是**要柯里化的函数**，不是数组 —— 我把整个方向做成了"数组怎么拆"
2. [ ] **参数要累积**：上次收的 + 这次收的（`adj.concat(nextadj)`）
3. [ ] 收够时调用**那个函数**：`fn.apply(this, adj)`
4. [ ] 内层返回的函数要 **`return`**

**`deepClone`（4 条）**
5. [ ] 类型判断的写法：`typeof x !== 'object'`（我写成了和**字符串** `'object'` 比）
6. [ ] 数组分支要 **`return x.map(item => deepClone(item))`** —— 递归结果要接住并返回（我调了 `map` 但没接，最后还返回了 `{}`，数组会被克隆成对象）
7. [ ] **`for...in` vs `for...of`**：`for...in` 拿**键名**，`for...of` 拿**值**（我自己标了这条）
8. [ ] `null` 要单独处理（`for...in null` 不报错、静默返回 `{}`）

**`throttle`（2 条）**
9. [ ] 返回的那个函数**不该再收 `fn` 参数** —— 会遮蔽外层的 `fn`
10. [ ] 时间到了要**调用**原函数并把参数传下去（`fn.apply(this, args)`）；`fn;` 单独一行什么都不做

**`countChars`（零提示题第 2 道）—— 3 条，其中第 12 条是今天最值钱的**
11. [ ] **"累加的起点"**：往对象里累加计数时，第一次遇到某个键，旧值是 `undefined` —— 得先给它一个 0 再 +1（`undefined + 1` 永远是 `NaN`）。**这一招他已经用过**：`myReduce` 里"取出旧值 → 算新值 → 写回去"，对象版只是把 `acc` 换成 `obj[key]`
