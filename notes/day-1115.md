## 九、⭐ 今天实战里最重要的一次"我错了"（他抓的）

他问：**"先说不能从 raw 转成 embstr，可我 SET 覆盖回 44 字节，为什么又变 `embstr` 了？"**

**他对，我讲错了。** 我原文只说"转换不可逆"，**漏了前提**。实测口径：

| 操作 | 编码会不会重算 |
|---|---|
| **`APPEND` / `SETRANGE` / `HDEL`（原地修改）** | **不降级**（升级后回不去） |
| **`SET` / `DEL`+重建（整个换对象）** | **按新值重算** |

→ **判据：`原地改`不降级，`重建`重新算。**

## 十、⭐ 另一个实测发现：**阈值 128 是错的，这台是 512**

我按"130 个 field 会转 `hashtable`"设计 T8，实测 **133 个还是 `listpack`**。

```bash
CONFIG GET hash-max-listpack-entries
512          ← Redis 7.4 把默认从 128 提到 512（zset 仍是 128）
```

→ **判据：默认值不要背，用 `CONFIG GET` 查实际值；不同版本、不同类型都不是同一个数。**
→ 也顺势教了：**`44` 是字节不是字符** —— 中文 3 字节/字，所以 `embstr` 只能装 **14 个汉字**（实测 14→42 字节 `embstr`，15→45 字节 `raw`）。
