## 二、`029_grants.sql`：三轮修完的三个 bug

| 轮 | Bug | 现场证据 | 根因 |
|---|---|---|---|
| 1 | **4 个角色全 `NOLOGIN`** | `rolcanlogin = f`（`reader_zhang` / `writer_li`） | `CREATE ROLE x;` 默认 `NOLOGIN` —— **8.1 第①题他答对过，写的时候又漏** |
| 2 | **现有序列只有 `SELECT`，缺 `USAGE`** | `nextval` → `permission denied for sequence users_user_id_seq` | `nextval` 需要 **`USAGE`**；`ALTER DEFAULT PRIVILEGES` 只管**以后**的序列 |
| 3 | **`rbac_writer` 没有现有表的 `SELECT`** | `SET ROLE writer_li; SELECT count(*) FROM users;` → `permission denied for table users` | 需求是"查+增删改"，`GRANT INSERT,UPDATE,DELETE` 漏了 `SELECT` |

**⭐ 附带撞出的知识点（我撞的）**：**`INSERT ... RETURNING` 需要目标表的 `SELECT` 权限** —— 我第一次用 `RETURNING` 测 writer，报 `permission denied for table users`，看着像 INSERT 被拒，其实 INSERT 有权限、**`RETURNING` 那部分要 SELECT**。→ 与 11/06「报错指向 A、根因在 B」同族。

**最终四条用例全绿**：reader SELECT ✓ / reader DELETE 报错 ✓ / writer SELECT ✓ / writer CREATE TABLE 报错 ✓。

## 三、主从复制七步：跑通 + 他踩的 8 个坑

**结果**：主库 `pg-a3` + **两个从库**（`pg-a3-replica` 宿主 5434、`pg-a3-replica2` 宿主 5435），主库 `pg_stat_replication` **两行 `streaming`**；**第二个从库的 `standby.signal` 和 `primary_conninfo` 全是他手写**（第⑦步变形）。

| # | 坑 | 正确 |
|---|---|---|
| 1 | `pg_hba` 的 database 填 `rabc` | **`replication`**（`all` 不含它；且 `rabc` 是拼写错） |
| 2 | 认证方式填密码 `123` | 填**方法名** `scram-sha-256`（**密码永不出现在 hba 里**） |
| 3 | 地址写单个容器 IP `172.19.0.3` | 写**网段** `172.19.0.0/16`（容器重建 IP 会变） |
| 4 | `pg_stat_replication` 在**从库**上查 → 0 行 | **主库**查 `pg_stat_replication`；**从库**查 `pg_stat_wal_receiver` |
| 5 | `CREATE TABLE` 在**从库**上跑 | **写操作永远在主库** |
| 6 | `primary_conninfo` 里 `port=5434` | **容器之间用 5432**（`-p 5434:5432` 左边是门外） |
| 7 | `primary_conninfo` 结尾加 `;` | **INI 格式不写分号** → `syntax error in ... line 1, near token ";"` |
| 8 | `CURRENT_TIMESTAMPTZ` | `CURRENT_TIMESTAMP` / `now()`（`TIMESTANPTZ` 是第二次错同一个词） |

**我的两笔账**：
- 让他解释六行日志时，**`was interrupted` / `entering standby mode` 的机制 / `timeline` 三处是我没讲过的** → 他当场指出"你出题问了我没讲的东西" → 已补讲（含 `redo LSN` / `checkpoint LSN` / `end LSN` 的分工）
