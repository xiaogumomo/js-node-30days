# 算法 · 类型 → 触发词 → 模板（自己的表）

> **用途**：algorithm 题的"思路"不是灵感，是**触发词**。看到特征 → 想到套路 ✓
> **练法**：① 一类型连做 3 题（不交叉）② 每做完写一行"触发信号" ③ 复习只过这张表（30 秒）④ 倒着练：给题先猜类型
> **怎么填**：每做完一题，把"我是靠什么信号想到这个类型的"写进第三列；新类型就加一行。

## 一、已做过的（4 题）

| 类型 | 触发词 / 数据特征 | 模板骨架 | 我靠什么信号想到的 | 做过的题 |
|---|---|---|---|---|
| **哈希表** | 找配对 / 两数之和 / "值当键" / 想从 O(n²) 降到 O(n) | 一边扫一边查表（存"我需要什么"）| —— | LC1 两数之和（O(n) 版）|
| **栈** | **配对** / 嵌套 / "最近的那个先处理" / 回退 | push 开括号；闭括号查栈顶，配不上就 false；最后栈要空 | 括号天然"后开先关" | LC20 有效的括号 |
| **一遍扫描维护状态** | 求**最大/最小差**、最大子段、连续区间 | 维护 1–2 个变量（最低价 + 最佳收益）| 需要"到目前为止的最好值" | LC121 买卖股票 |
| **双指针（写指针）** | **原地修改** + **保持顺序** + 把某类元素挪到一边 | `slow` 写、`fast` 读；扫完补尾部 | 要求原地、不许新建数组 | LC283 移动零 |
| **双指针（左右相向）** | **有序** + 找一对 / 去重 / 回文；**或**"两端取面积/体积" | `left`/`right` 从两端相向；**和太小 → left 右移；太大 → right 左移**；**面积题：哪边矮就淘汰哪边** | LC167：⚠️ **AI 给的信号**（我原本"正负分区 + 哈希"，超时 55 分钟）→ **"有序"就是钥匙**；LC11：⚠️ **AI 给的关键一步**（"移动矮的那条"的证明，超时 22 分钟）→ **信号 = 两端 + 每步淘汰一个** | LC167 两数之和 II / LC11 盛最多水的容器 |

## 二、还没做的类型（每类连做 3 题再开下一类）

| 类型 | 触发词 / 数据特征 | 模板骨架 | 候选题 |
|---|---|---|---|
| **双指针（左右相向）** | **有序数组** + 找一对 / 去重 / 回文 | `left`/`right` 相向走，按比较结果移动一侧 | LC167 两数之和 II / LC125 验证回文串 / LC11 盛水容器 |
| **滑动窗口** | **最长/最短的连续**子串或子数组 满足某条件 | 右端扩张 → 条件破了就收缩左端 → 记录答案 | LC3 无重复最长子串 / LC209 长度最小子数组 |
| **二分查找** | **有序** + 找某个值/边界 + 目标 O(log n) | `left`/`right`/`mid`；边界用 `<=` 还是 `<` 要统一约定 | LC704 二分查找 / LC35 搜索插入位置 / LC34 找首尾位置 |
| **链表** | 反转 / 环 / 合并 / "只能一个个走" | 虚拟头节点 `dummy` + 双指针（prev/cur/next）| LC206 反转链表 / LC141 环形链表 / LC21 合并有序链表 |
| **递归 / DFS** | 树 / 嵌套结构 / "每条路都要走一遍" | 递归出口 → 处理当前 → 递归子问题 | LC104 二叉树最大深度 / LC226 翻转二叉树 |
| **贪心** | "每一步取最优""区间调度" | 排序后按规则扫一遍 | LC455 分发饼干 / LC435 无重叠区间 |
| **动态规划（入门）** | 求"最多/最少/方案数"且**当前状态依赖之前状态** | 定义 `dp[i]` 含义 → 转移方程 → 初值 → 遍历顺序 | LC70 爬楼梯 / LC198 打家劫舍 / LC53 最大子数组和 |

## 三、每题的"触发信号"怎么记（示例）

做完 LC283 后要写的三行：
```
题：LC283 移动零
信号：原地改 + 保序 + 挪某类元素 → 双指针（写指针）
骨架：slow 写、fast 读；扫完补尾
```
→ **复习时看这三行，不用重做题目** ✓

## 四、倒着练（每天 1 分钟，不需要会做）

随机挑一道**没做过的题**，只回答两个问题：
1. **我猜是哪个类型？**
2. **我从哪句话/哪个数据特征猜的？**
（猜错的价值最大 —— 说明那个触发词还没连上 ✓）
